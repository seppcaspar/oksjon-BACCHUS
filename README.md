### Bacchus

school project
The example picture and instructions can be found in reference_material folder
# features:
-category filter
-users can bid on their name
-bids are saved and can be checked later
-auctions expire after some time and then dont show


## Needed

- **Node.js**

## Frontend 
```
cd frontend
npm i
npm run dev
```

## Backend
```
npm i
npm start
```
